# Terrain Classification for Legged Robots Using Deep Learning on Tactile Data

This repository contains the source code for the UE24CS352A Machine Learning Mini-Project[cite: 7]. The project implements a 1D Convolutional Neural Network (CNN) to classify ground surfaces using mid-step tactile sensor data.

## Environment Setup
1. Clone this repository to your local machine.
2. Ensure you have Jupyter Notebook installed.
3. Install the required dependencies by running:
